# 🖐️ Contributing

Thank you for your interest in contributing!

## 📝 Guidelines

1. **Issues**: Before making major changes, please open an issue to discuss your proposed feature or bug fix.
2. **Development Branch**: Create feature branches from `dev`.
3. **Pull Requests**: Submit PRs against the `dev` branch with a summary of changes.
4. **Code Quality**: Ensure code is formatted and passes lint checks.

```bash
cd js
bun run lint
```
